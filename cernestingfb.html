Nesting Flower Bowls

Not For Sale

Medium: Stoneware with Glaze

Dimensions: Smallest Bowl: 3.5"H x 5.5"W x 3"D, Medium Small Bowl: 3.75"H x 6.5"W x 3.25"D, Medium Large Bowl: 4.25"H x 7.5"W x 3.75"D, Largest Bowl: 4.5"H x 8.75" x 4"D

Description: Set of four nesting bowls, each with five petals shaped into rim. Exterior of each bowl features a sage green glaze. Interiors feature a light pink glaze that pools inside each bowl.

Further Information: This nesting bowl set was inspired by the first challenge in first episode of the Great Pottery Throwdown (great show if you haven't watched it). Executing the floral shape of these bowls was particularly challenging because if the petals were slightly misaligned or the bowls slightly warped, then they would no longer fit into each other. Ensuring they were aligned required much planning and trigonometry, but I am extremely happy with the final set.
